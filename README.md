# Shorts STEAM Lab

«Бір идея — мың мүмкіндік!» — платформа видеоуроков-шортсов для учителей
Мағжан Жұмабаев атындағы №19 орта мектеп-гимназия (Талдықорған).

Мобильное веб-приложение (PWA): открывается по ссылке, ставится на главный экран телефона, интерфейс на казахском.

## Что умеет

| Раздел | Что внутри |
|---|---|
| **Басты бет** | Описание платформы, 5 направлений STEAM, новые видео, «Назар аударыңыз!», контакты |
| **Лента** | Все загрузки учителей: поиск, фильтр по STEAM, плеер-шортсы со свайпом, лайки, «Бөлісу», жалоба |
| **«+»** | Загрузка: видео-файл (до 50 МБ, с превью и прогрессом), ссылка YouTube/Shorts, пост с фото/текстом. Выбор раздела STEAM, предмета, класса |
| **Lab** | «Shorts STEAM Lab» + логотип, 5 папок (Science, Technology, Engineering, Art, Mathematics). Публикуют только админы |
| **Кабинет** | ФИО, предмет, роль, число загрузок/видео/лайков, мои публикации (редактирование, удаление), смена пароля |
| **Басқару панелі** (админ) | Қолданушылар — список с числом загрузок, назначить админом, заблокировать, выдать временный пароль, удалить. Посттар — все публикации, перенос в Lab. Модерация — жалобы. Хабарландырулар — объявления для всех |
| Колокольчик | Объявления и новые идеи в Lab, счётчик непрочитанных |
| Көмекші | Помощник: частые вопросы и генератор идей для урока |

Регистрация — по почте и паролю, сессия сохраняется (не нужно входить каждый раз).
**Первый зарегистрированный пользователь автоматически становится администратором.**

## Режимы работы

- **ДЕМО** (по умолчанию, пока не указаны ключи Supabase): всё работает, но данные хранятся только в браузере
  этого устройства. Демо-админ: `admin@demo.kz` / `demo123`.
- **Боевой**: данные в Supabase (бесплатный тариф) — общие для всех учителей.

## Подключение базы (≈5 минут)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) → **New project** (регион — Frankfurt, `eu-central-1`).
2. **SQL Editor → New query** → вставьте весь файл `supabase/schema.sql` → **Run**.
   Создаются таблицы, защита (RLS), хранилище `media` и функции админа. Скрипт можно запускать повторно.
3. **Authentication → Sign In / Providers → Email** → выключите **Confirm email**.
   Иначе учителям придётся подтверждать почту, а встроенная почта Supabase отправляет письма только участникам проекта.
4. **Authentication → URL Configuration** → **Site URL** = адрес сайта (например `https://shorts-steam-lab.vercel.app`),
   добавьте его же в **Redirect URLs**.
5. Кнопка **Connect** вверху проекта (или **Project Settings → API Keys**) → скопируйте **Project URL** и **anon / publishable** ключ.
6. Укажите ключи одним из способов:
   - Vercel → Project → Settings → Environment Variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` → Redeploy;
   - или впишите их в `public/config.js` (`supabaseUrl`, `supabaseKey`) и задеплойте.
7. Откройте сайт и зарегистрируйтесь первым — вы станете администратором.

Сделать админом другого человека: в кабинете админа → Қолданушылар → «Әкімші ету»,
или SQL: `update public.profiles set role = 'admin' where email = 'mail@example.com';`

### Лимиты бесплатного тарифа Supabase

- файл — до **50 МБ**, хранилище — **1 ГБ**, трафик — **5 ГБ/мес**, база — 500 МБ;
- проект **засыпает после 7 дней без активности** (например, на каникулах) — его включают кнопкой Restore в панели Supabase;
- когда видео станет много: тариф Pro (от $25/мес, 100 ГБ) или публикация длинных роликов через YouTube-ссылку (раздел «Сілтеме»).
  Лимит размера файла в приложении меняется в `public/config.js` → `maxVideoMb`.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

Стек: React 19 + Vite, Supabase (Auth, Postgres, Storage), lucide-react, шрифт Nunito. Маршруты на `#/…`,
поэтому хостинг не требует настроек переадресации.

```
src/
  pages/        Welcome, Auth, Home, Feed, Lab, Upload, Cabinet, Admin, Notifications, Helper, PostPage
  components/   плеер-шортсы, карточки, нижнее меню, общие блоки
  lib/api/      supabase.js (боевой), local.js (демо) — одинаковый интерфейс
  assets/       логотип и 3D-иконки из макета
supabase/schema.sql   схема БД, RLS, хранилище, функции админа
public/config.js      ключи Supabase без пересборки
```

## Безопасность

- RLS на всех таблицах; почта учителей видна только админам.
- Учитель не может поменять себе роль, счётчики лайков, публиковать в Lab или удалять чужое.
- Файлы загружаются только в свою папку хранилища; заблокированный пользователь не может публиковать.
- Временный пароль от админа хранится как bcrypt-хеш (как в Supabase Auth).
